# PHPMailer Library

This directory should contain the PHPMailer library files.

## Installation

Download PHPMailer from: https://github.com/PHPMailer/PHPMailer

Extract the following files to this `src/` directory:
- `src/PHPMailer.php`
- `src/SMTP.php`
- `src/Exception.php`

Or use Composer:
```bash
composer require phpmailer/phpmailer
```

Then copy the files from `vendor/phpmailer/phpmailer/src/` to this `src/` directory.
